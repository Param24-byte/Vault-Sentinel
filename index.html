Traffic scoring
Analyses call history — APIs silent 90+ days classified Dormant, 1+ year become Zombie. Sudden spikes on dead endpoints trigger critical resurrection alerts.
Static scoring
Checks auth type, documentation status, team ownership and CVE count in dependency chain. No auth + no docs + no owner = near-maximum risk.
ML scoring
Predicts future zombies by detecting declining traffic trends, team restructuring signals and replacement API launches before dormancy sets in.
